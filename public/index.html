Encryption Architecture

Credentials in Orcha Agent are never stored in plaintext. They are encrypted using an initialization vector (IV) and a 32-byte secret key:

Ciphertext = AES-256-CBC(Data, ENCRYPTION_KEY, IV)
  • Dynamic self-healing: Agent requests missing key in chat and updates vault automatically.
  • Scoped per User ID with strict row isolation.
  • Decryption happens strictly in-memory during tool invocation.
